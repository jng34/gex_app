# GEX Dashboard

A Streamlit web application for visualizing Gamma Exposure (GEX) profiles for stock options.

## Features

- Input any stock ticker symbol
- Select expiration dates
- View net Gamma Exposure (GEX) bar chart
- Identify Gamma Flip points
- Raw data table

## Installation

1. Clone the repository
2. Create a virtual environment: `python -m venv .venv`
3. Activate the virtual environment: `.venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`

## Usage

Run the app: `streamlit run gex_app.py`

Or use the batch file: `run_app.bat`

## Requirements

- Python 3.8+
- Dependencies listed in requirements.txt
